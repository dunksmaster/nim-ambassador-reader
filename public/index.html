Ambassador reader

Paste the URL of an ambassador, campus, or developer-champion page. The demo fetches the page and returns a small JSON record. Fields the page does not state are null.

The JSON record will show up here.


    

      Extraction uses NVIDIA NIM via build.nvidia.com
      (model nvidia/nemotron-3-super-120b-a12b).
      Source: github.com/dunksmaster/nim-ambassador-reader.
    

    
About 5 requests per minute on each server instance. Check the source page before relying on a field.
